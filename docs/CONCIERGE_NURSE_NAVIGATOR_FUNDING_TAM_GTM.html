GTM Strategy — Land Direct, Expand to Embed, Compound via Connectors

Phase 1 · Land (0–12 mo)

Consumer direct — the owned record

  • Concierge subscription ($25–100/mo anchor: General Medicine visits at $25, Sunny-style text-first UX)
  • One killer flow end-to-end: symptom/lab → in-network, in-state provider booked this week
  • Vault = switching cost; record persists across jobs/plans — no incumbent can offer this
Phase 2 · Expand (12–24 mo)

B2B2C embed + connector distribution

  • White-label to employers/brokers (Thatch/Pager/Sunny demand: SemperVirens backs both Thatch & Sunny)
  • OpenAI plugin / Claude connector: empty directory, cheap distribution — PHI-free pre-handoff (no BAA from OpenAI yet)
  • Per-booking / steerage fees from providers (Zocdoc-in-Gemini model)
Phase 3 · Compound (24 mo+)

Data moat + workflow depth

  • Machine-readable provider catalog (condition · price · state · insurance) becomes the matching asset
  • Phone/fax agentic booking reaches practices APIs never will (Sunny's edge, applied consumer-side)
  • Deeper workflow: prior auth, referrals, denials — the $35B PA layer, patient-advocate-side
